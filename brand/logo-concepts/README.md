# ByteFolk Open Herd logo assets

The Open Herd concept has two intentional lockups:

- `bytefolk-concept-c-open-herd-mark.svg` is the organization icon. It contains only the selected Open Herd graphic and is used in compact UI surfaces such as the organization tree, project switcher, and avatars.
- `bytefolk-concept-c-open-herd.svg` is the full horizontal lockup. It includes the `ByteFolk` wordmark and is reserved for organization profiles, brand pages, documentation covers, and other contexts with enough room for the complete identity.

Do not substitute the full lockup for the organization icon. The icon must remain legible without a wordmark.
